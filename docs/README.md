# ACLP specification

| Document | Defines |
| --- | --- |
| [Protocol](protocol.md) | Messages, validation, requests, notifications, identity, ordering, consent, and the HTTP and stdio bindings. |
| [Events](events.md) | Event names, emission boundaries, scopes and parameter definitions. |
| [Schema](schema.md) | The Draft-07 schema for envelopes, event parameters, discovery and shared types. |

The protocol and event reference define behavior; the schema defines message structure. Implementations must satisfy both.
